# Prompt 06 - Code Review

## Tool

OpenAI Codex, in a new review task separated from implementation.

## Role

Senior Software Reviewer.

Review: - Architecture - Clean Code - Security - Performance -
Maintainability - Tests

Classify findings: Critical / High / Medium / Low / Suggestion

Do not modify code before presenting findings.

Review the implementation against the approved requirements,
architecture, API contract, acceptance criteria, and test strategy. Do
not rely on undocumented implementation assumptions.
