# Glossary

  -----------------------------------------------------------------------
  Término                          Definición
  -------------------------------- --------------------------------------
  Vibe Coding                      Desarrollo guiado mediante lenguaje
                                   natural y agentes de IA.

  Agente IA                        Sistema capaz de analizar, planificar
                                   e implementar tareas.

  Codex                            Agente utilizado para análisis,
                                   arquitectura, backend, pruebas,
                                   despliegue y revisión.

  Antigravity                      Herramienta utilizada para diseñar e
                                   implementar el frontend.

  Contrato de API                  Especificación aprobada de endpoints,
                                   datos y comportamientos compartida
                                   entre backend y frontend.

  Prompt                           Instrucción enviada a una IA.

  MVP                              Producto mínimo viable.

  CI/CD                            Integración y despliegue continuo.

  ADR                              Registro de decisiones
                                   arquitectónicas.

  DTO                              Objeto de transferencia de datos.

  ORM                              Herramienta de mapeo
                                   objeto-relacional.

  API REST                         Interfaz HTTP basada en recursos.

  Pull Request                     Solicitud de integración de cambios.

  Railway                          Plataforma de despliegue del backend y
                                   PostgreSQL.

  Vercel                           Plataforma para desplegar el frontend.

  Prisma                           ORM utilizado por el backend.

  NestJS                           Framework backend.

  React                            Biblioteca para frontend.
  -----------------------------------------------------------------------
