# Project Vision

## Visión

Convertir VibeQuiz en un repositorio de referencia para aprender
desarrollo de software asistido por Inteligencia Artificial.

## Misión

Demostrar que una aplicación puede construirse de manera profesional
utilizando Vibe Coding, agentes especializados y supervisión humana.

## Principios

-   Transparencia
-   Documentación primero
-   Código limpio
-   Automatización
-   Reproducibilidad
-   Aprendizaje continuo
-   Separación de responsabilidades entre agentes
-   Aprobación humana en puntos de control

## Modelo de colaboración

Codex asumirá roles especializados en tareas separadas para análisis,
arquitectura, backend, pruebas y revisión. Antigravity desarrollará la
experiencia frontend sobre contratos previamente aprobados. El
desarrollador coordinará ambas herramientas y conservará la autoridad
sobre las decisiones y la aprobación final.

## Valor del proyecto

Más que una plataforma de cuestionarios, VibeQuiz documenta el proceso
completo de ingeniería de software moderna.
