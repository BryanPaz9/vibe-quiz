# Project Charter

# VibeQuiz

## Propósito

Desarrollar una plataforma educativa de cuestionarios como caso de
estudio para demostrar un flujo moderno de desarrollo basado en Vibe
Coding, agentes de IA y supervisión humana.

## Justificación

El proyecto busca mostrar que la IA puede acelerar el desarrollo de
software cuando existe una arquitectura definida, prompts de calidad y
revisión humana.

## Objetivo General

Construir una aplicación web funcional y documentar todo su ciclo de
vida.

## Objetivos Específicos

-   Implementar un MVP.
-   Documentar arquitectura y decisiones.
-   Publicar código y prompts.
-   Desplegar públicamente la solución.

## Stakeholders

-   Estudiantes
-   Docente
-   Equipo de desarrollo (IA + desarrollador)
-   Comunidad Open Source

## Equipo y responsabilidades

-   **OpenAI Codex:** análisis, arquitectura, backend, pruebas,
    despliegue y revisión independiente.
-   **Antigravity:** diseño e implementación del frontend.
-   **Desarrollador:** coordinación, integración, validación y aprobación
    final.

## Entregables

-   Frontend
-   Backend
-   Base de datos
-   Documentación
-   Pruebas
-   Despliegue
-   Repositorio GitHub

## Restricciones

-   Tiempo limitado al seminario.
-   Arquitectura sencilla.
-   Sin funcionalidades fuera del MVP.

## Criterios de éxito

-   Aplicación funcional.
-   Despliegue público.
-   Documentación completa.
-   Repositorio reproducible.
