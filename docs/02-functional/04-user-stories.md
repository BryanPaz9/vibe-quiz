# Historias de usuario

## Administración

### US-001 — Acceder al panel

Como administrador, quiero acceder de forma autorizada al panel para
gestionar cuestionarios y resultados.

Relacionada con: `FR-001`.

### US-002 — Crear un cuestionario

Como administrador, quiero crear un cuestionario con preguntas y
opciones para preparar una actividad.

Relacionada con: `FR-002`, `FR-006`, `FR-007`.

### US-003 — Consultar cuestionarios

Como administrador, quiero ver los cuestionarios existentes y su detalle
para administrarlos.

Relacionada con: `FR-003`.

### US-004 — Editar un cuestionario

Como administrador, quiero modificar un cuestionario editable para
corregir o mejorar su contenido.

Relacionada con: `FR-004`, `FR-006`, `FR-007`.

### US-005 — Eliminar un cuestionario

Como administrador, quiero eliminar un cuestionario cuando sea válido
hacerlo para mantener organizada la plataforma.

Relacionada con: `FR-005`.

### US-006 — Compartir un cuestionario

Como administrador, quiero obtener una URL de participación para
compartir el cuestionario con estudiantes.

Relacionada con: `FR-008`.

### US-007 — Consultar resultados

Como administrador, quiero consultar las participaciones y puntuaciones
para evaluar los resultados de la actividad.

Relacionada con: `FR-019`.

### US-008 — Consultar ranking

Como administrador, quiero ver las posiciones del cuestionario para
comparar los resultados.

Relacionada con: `FR-020`, `FR-021`, `FR-022`.

## Participación

### US-009 — Abrir un cuestionario

Como participante, quiero abrir un cuestionario mediante una URL para
conocer la actividad disponible.

Relacionada con: `FR-009`.

### US-010 — Identificarme

Como participante, quiero proporcionar la identificación mínima
necesaria para que mi resultado pueda reconocerse.

Relacionada con: `FR-010`.

### US-011 — Iniciar el intento

Como participante, quiero iniciar una participación válida para
responder el cuestionario.

Relacionada con: `FR-011`.

### US-012 — Responder preguntas

Como participante, quiero seleccionar una opción para cada pregunta para
completar el cuestionario.

Relacionada con: `FR-012`, `FR-013`.

### US-013 — Enviar respuestas

Como participante, quiero enviar mis respuestas para que sean
calificadas.

Relacionada con: `FR-014`, `FR-015`, `FR-016`, `FR-017`.

### US-014 — Consultar mi resultado

Como participante, quiero ver el resultado permitido al finalizar para
conocer mi desempeño y comparar mis respuestas con las correctas.

Relacionada con: `FR-018`.

### US-015 — Consultar ranking

Como participante, quiero consultar el ranking cuando sea público para
conocer mi posición.

Relacionada con: `FR-020`, `FR-021`, `FR-022`.

## Sistema y operación

### US-016 — Recibir errores comprensibles

Como usuario, quiero recibir mensajes consistentes cuando una operación
no sea válida para saber cómo continuar.

Relacionada con: `FR-024`.

### US-017 — Verificar disponibilidad

Como responsable de operación, quiero comprobar la salud del backend y
la base de datos para diagnosticar el despliegue.

Relacionada con: `NFR-017`.

## Visitantes

### US-018 — Comprender los recorridos de la plataforma

Como visitante, quiero explorar en la landing las etapas del
administrador y del participante para comprender ambas experiencias
antes de comenzar.

Relacionada con: `FR-025`, `NFR-013`, `NFR-015`.
